Campus Selection System
A web-based campus placement management application built with Python,
Django, PostgreSQL, HTML, CSS, and JavaScript. It organizes student
records and job applications and provides separate access for students,
administrators, and recruiters.
Repository: https://github.com/Pradipk2004/campus_selection_system
Features
- Role-based access: Separate access for students, administrators,
  and recruiters.
- Placement records: Manage student information and job
  application records.
- PostgreSQL database: Uses a normalized schema for
  placement-related data.
- Access control: Restricts application functionality according to
  user roles.
- Data protection: Includes field-level encryption and secure file
  storage.
- Web interface: Interfaces for all three user roles, built with
  HTML, CSS, and JavaScript.
Technology Stack
  Layer             Technologies
  Backend           Python, Django
  Database          PostgreSQL
  Frontend          HTML, CSS, JavaScript
  Version control   Git, GitHub
User Roles
- Students: Access student-facing placement workflows.
- Administrators: Manage placement-related records and workflows.
- Recruiters: Access recruiter-facing placement workflows.
Available actions depend on the permissions configured for each role.
